One sentence of at most 200 characters explaining the modern internet to a time traveler who has just stepped out of the year 1800. It builds only from what a person from 1800 already knows — libraries, post offices, roads, letters, books, a spoken word — and leaves one picture: all of them joined by roads of light, so a message reaches anyone, anywhere, in a blink.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program is deterministic, uses only the Python 3 standard library, needs no network, and writes a single line of 1–200 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
